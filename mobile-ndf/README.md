# Mobile NDF

Prototype front mobile Expo Go pour l'application de notes de frais FFS/EFS.

## Lancer le projet

```bash
npm install
npm run start
```

Ensuite, scanner le QR code avec Expo Go.

## Structure

- `App.tsx` : navigation mobile simple.
- `src/screens` : écrans de l'application.
- `src/components` : composants réutilisables.
- `src/theme` : couleurs, espacements, styles partagés.
- `src/data` : données mockées pour coder le front sans backend.
